# Production checklist — one content piece

Copy this section into your notes for each piece, or duplicate rows in published-log.csv.

**Piece #:** ___  
**Title:** ___  
**Planned date:** ___

---

## Pre-production

- [ ] Hook written (≤ 15 words, states the payoff)
- [ ] CTA chosen (one URL only — see RUNBOOK)
- [ ] Screen / tabs closed except: tester, browser, script
- [ ] Mic check if voiceover

---

## Record (10–15 min)

- [ ] **Talking head OR screen only** — pick one style for the piece
- [ ] Screen record at 1080p (OBS, QuickTime, or Loom)
- [ ] If Census piece: show city select → metrics → run → results table
- [ ] Keep under 90 seconds raw (edit tighter)

---

## Edit (15–20 min)

- [ ] Trim dead air and loading spinners
- [ ] Add captions (CapCut, Descript, or YouTube auto-captions)
- [ ] Export 9:16 for Shorts/TikTok OR 16:9 if YouTube long-form
- [ ] Thumbnail: one stat or city name on screen (optional)

---

## Publish (15 min)

- [ ] **YouTube Short** — title = hook; description = CTA link + one sentence
- [ ] **X thread** — 4–5 tweets (see calendar.md template)
- [ ] Optional: TikTok/Reels — same file, same caption
- [ ] Update [published-log.csv](./published-log.csv): status `published`, URLs, date

---

## Post-publish (5 min)

- [ ] Reply to any comments for 24h
- [ ] If strong engagement → queue follow-up piece in same vein
- [ ] Share link in vendor outreach Email 2 as social proof (optional)

---

## Time budget

| Step | Minutes |
|------|---------|
| Script + setup | 10 |
| Record | 15 |
| Edit | 20 |
| Publish + thread | 15 |
| **Total** | **~60** |

Batch 4 pieces on one Saturday ≈ 4 hours with breaks.
