# Content acquisition — weekly runbook

**Goal:** Attract data buyers (engineers, analysts, researchers) via short video + threads → Census tester → reviews/marketplace.

**Primary channel:** YouTube Shorts (60–90s) + X thread (same script).  
**Secondary:** Repost Short to TikTok/Reels optional.

**Cadence:** Batch 2–4 pieces every Saturday (~2–4 hours).

---

## Before you start

- [ ] Census tester works: `/marketplace/census-data-api/help`
- [ ] Replace `BASE` in CTAs with your live domain
- [ ] YouTube channel + X account ready
- [ ] Copy [published-log.csv](./published-log.csv) for tracking

---

## Weekly batch checklist

### Phase 1 — Pick pieces (10 min)

- [ ] Open [calendar.md](./calendar.md)
- [ ] Choose **2 pieces** this week (recommended: one data reveal + one product demo)
- [ ] Mark `planned_date` in published-log

**Priority order if behind:** Pieces **1, 3, 5** first (strongest product proof).

---

### Phase 2 — Produce each piece (45–50 min × N)

For **each** piece, follow [production-checklist.md](./production-checklist.md):

- [ ] Script hook (one sentence)
- [ ] Screen record
- [ ] Edit + captions
- [ ] Upload Short
- [ ] Post X thread
- [ ] Optional: TikTok repost
- [ ] Log in published-log.csv

---

### Phase 3 — Distribute (15 min per piece)

- [ ] **Show HN** — only for Piece 12 / major launch (once)
- [ ] **r/datasets** or **r/dataengineering** — Piece 1 or 4 (data reveal, not salesy)
- [ ] **Newsletter pitch** — after 3+ pieces live (Data Engineering Weekly, etc.)

---

## CTA rules (one per video)

| Piece type | CTA |
|------------|-----|
| Census / city data | `{BASE}/marketplace/census-data-api/help` |
| Vendor list / reviews | `{BASE}/companies` or `{BASE}/companies/{slug}/review` |
| Marketplace / MCP | `{BASE}/marketplace` or Developer Hub MCP config |
| General intro | `{BASE}` |

Never stack three CTAs in one 60s video.
